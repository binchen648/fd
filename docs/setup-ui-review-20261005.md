# 选人与 3X 准备界面复核

日期：2026-10-05。范围为现有 8 名御主、8 名从者的准备界面。

## 本轮调整

- 自选资料区使用卡图与姓名摘要、完整宽度的技能列表；保留原有选人和阶段动画。
- 搜索支持忽略名称中的空格，增加清空按钮与清除搜索／职阶筛选入口。御主、从者分别记住搜索条件，返回步骤时恢复。
- 卡片显示两行长名称，并提供完整名称提示；初始与后续选中状态同步 `aria-pressed`。
- 3X 进度条明确标出已完成与当前步骤。玩家选中禁用目标时显示待确认，全体禁用完成后才显示锁定。
- 圣晶石项目使用统一线条图标、价格和 44 像素购买按钮。区分余额不足、达到上限、从者候选已满，并显示购买后的候选数量和剩余余额。
- 下一步改为“继续选择从者”；选人、购点、准备完成的主操作仍位于底部中央。
- 调整 1280 宽度的禁用卡图高度，确保现有八张禁用卡完整可见。

## 验证

- `node tools/verify-interface-redesign.cjs`：1280×720、1920×1080 的自选和完整 3X 准备流程、购买扣款、新从者候选插入、按钮边界通过。
- `node tools/verify-selection-art.cjs`：姓名搜索、空格归一化、清空、搜索条件恢复、职阶组合筛选、重置筛选、模拟 90 张卡片无横向溢出、八张禁用卡可见通过。
- `node tools/verify-mobile-setup.cjs`：844×390、740×360、932×430 横屏的自选、3X、购点、确认按钮边界通过。
- 检查生成的选人及购点截图，无浏览器页面脚本错误。

90 张卡片仅为布局模拟，没有导入额外角色。横屏检查使用桌面浏览器模拟尺寸，没有实机手机验收。本轮未接入技能或修改对局规则。
