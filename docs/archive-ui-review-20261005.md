# 图鉴界面统一复核

日期：2026-10-05。范围为现有图鉴内容及桌面、横屏界面。

## 调整

- 四个分类统一为与准备界面一致的导航、筛选、卡片姓名栏和颜色。
- 补齐基础攻击、局势、事件详情的新版布局标记。与角色详情共用卡图展示、标题、内容区和滚动条；卡牌详情单独突出魔耗、威力、恢复魔力、战果和实体数量。
- 各分类增加名称搜索、结果计数、清空按钮、空结果提示和重置筛选。搜索仅隐藏不匹配卡片，保留原有切换与卡片动画。
- 分别记住四类名称搜索；从详情返回恢复搜索、列表位置与原卡片焦点。
- 从者卡组扩大图片与说明空间，保留数量标记和原始卡图比例。
- 补齐横屏图鉴列表与详情布局。
- 修复鼠标移开卡图后放大预览残留、遮挡正文的问题。

## 验证

- `node tools/verify-codex-ui.cjs`：624 项检查通过，覆盖 16 个角色、18 张基础攻击、13 张局势、16 种共 20 张冬木事件的资源、文案、数值、图片比例、卡组数量、筛选、预览、返回与焦点恢复。
- `node tools/verify-archive-layout.cjs`：检查 1280×720、1920×1080、844×390、740×360 的四类搜索、清空、重置、搜索条件恢复和布局边界，额外复核放大预览退出。
- 截图保存在 `ui-preview/design-review/archive/`。

横屏使用桌面 Edge 模拟尺寸，未做手机实机验收。本轮没有修改规则或技能定义。
