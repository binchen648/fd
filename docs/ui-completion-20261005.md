# UI 布局与对局呈现优化验收

## 已完成范围

- 使用中性深灰、白字与灰白主动作，不再使用蓝色、橙色或金色作为全局主题。角色卡、地图和背景插画保留原色。
- 模式卡片统一四行信息布局、标题与说明基线、底部入口；圆角与悬停抬升、图片微缩放形成同一反馈。
- 教程侧栏改为编号与标题对齐的独立导航；翻页固定三列；图文区域居中，保留内容滚动与完整规则。
- 全局返回按钮、页面标题基线、输入框高度、主动作按钮、档案面板和购点卡底部操作统一整理。
- 主页特效包括背景轻移、鼠标微视差、轮廓光、前景薄雾、柔光掠过与 18 个独立光粒；小横屏减少粒子，减少动态效果偏好停用动画与鼠标微视差。
- 用户追加的对局美术与动画已纳入：阶段提示、对手资料比例、玩家面板、手牌选中、地图动作边框、令咒与技能弹窗、记录与弃牌弹窗、结算与胜利呈现统一。牌落位与令牌到达改为短时淡入移动，保留实际飞牌；技能卡各行高度与按钮位置统一。

- verify-ui-finish：设置/背景/音乐/音效、档案/头像/晋升、教程/图鉴/选人、真实对局入口，以及技能/记录/退出/弃牌/选择/结算/胜利画面通过；对局双方对手组与每个操作按钮边界检查通过。
- verify-mobile-setup：844/740/932 横屏的自选与完整 3X 禁用、抽御主、圣晶石购买、抽从者与准备流程通过。
- verify-guide-layout、verify-archive-layout、verify-selection-art、verify-arena-ui：教程图解与跳转、五类图鉴与独立搜索、90 名角色模拟、主页白字与黑字悬停、多人入口通过。
- verify-project-theme：各主要页面与 Shadow DOM 对局实际配色通过，粒子随时间移动检查通过。
- verify-full-game-flow：实际运行的开局与补牌飞入、令牌/卡到达、数值反馈、AI 推进、部署/移动、地区结算和地图中人数/出牌位置检查通过。

## 验证边界

- 横屏为浏览器模拟，未使用手机硬件。隐藏结算和胜利截图部分使用真实 UI 渲染器的视觉夹具，实际规则流程另由 verify-full-game-flow 检查；本轮未声称所有玩法与完整一局无 bug。
- 未接入技能保持关闭；经典模式仍等待角色池补齐后开放。没有修改规则或新增联机服务。
- 完整截图索引：ui-preview/design-review/finished/index.html。

## 空部署位与金色恢复

根据用户明确指出的所有区域空框问题，所有 .land-slot 空部署位去掉不透明底、粗边与阴影，使用轻量加号和细底线；占用时保留角色头像与金色细边，地点奖励不变。全局交互恢复暖金 #d6ae52 与深色底，主页白字及插画原色保留。资源版本 20261005-gold-slots。

## 圆形部署位与操作区稳定性修复

根据最新反馈，所有地区的空部署位和占用头像统一恢复圆形，移除加号与方形占位。操作区不再对每次状态快照重写 innerHTML，按原有按钮节点更新属性和变化文案；等待其他玩家时，移动/出牌步骤共用固定等待布局，避免操作区反复增减按钮。倒计时只更新实际变化的文字。增加回归检查：连续 12 次远端玩家移动/出牌步骤更新后，按钮节点保持、无子节点替换、面板高度不变、全部部署位圆形。资源版本 20261005-round-stable。
