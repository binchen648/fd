## Technical Review

The helper is byte-equal to the historically accepted source. It recognizes an
exact type-only condition and compares a nonempty authoritative movement-event
location with the existing controller's nonempty current location. Wrong event
type, absent controller, missing/malformed location fail closed. It deliberately
does not infer opponent relationship or battlefield eligibility; those remain
separately composed conditions. The equality helper relies on trusted game state
and event producers, not a new full-map/context authentication mechanism.

Loader admission is tighter than the source: direct ability conditions only.
Nested logical/effect/target/modifier placements and payload fields remain
disabled. Runtime rejects malformed payloads and the trusted event hook rolls
back such failures. Opponent admission is limited to the existing movement event
with an exact direct `event_player_is_opponent` condition. Other controller-scoped
events remain restricted; no new trigger type or movement-emission route is added.

The independent probe uses loader-produced authoring, a seven-seat state and
the real core move action. An opponent actually entering the controller's
battlefield emits the existing movement event and applies exactly one +2 mana
reward; caller state stays unchanged. Reward rather than closure separates this
new relation test from the inherited close-rule issues already recorded.
