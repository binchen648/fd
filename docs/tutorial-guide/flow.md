# 先了解这场圣杯战争

你控制一名御主与一名从者，在冬木市选择地点、使用卡牌，并争取战果。合计威力决定一场战斗的胜负，累计战果决定整局排名。

## 三项重要资源

| 信息 | 用途 | 通常的初始值或上限 |
| --- | --- | --- |
| 魔力 | 支付移动、出牌及能力的费用 | 初始 4 点，上限 12 点；特殊御主另有说明 |
| 令咒 | 使用令咒能力，每枚通常只能使用一次 | 初始 3 枚 |
| 战果 | 决定高潮淘汰与最终胜负 | 随战斗、侦察和卡牌效果累计 |

令咒是独立资源，不属于攻击牌。花费令咒可以获得魔力、移动或增强战斗收益，具体使用时机与效果以令咒能力说明为准。

## 令咒怎么用

通常在自己的行动阶段，每消耗一枚令咒，选择一种用途：获得 4 点魔力；进行一次令咒移动；或本回合合计威力增加 2，且在符合条件的战斗获胜后额外获得 2 点战果。

回魔仍受魔力上限限制。令咒移动与常规移动分别处理，不能因为常规移动不可用，就直接认定令咒移动也不可用。特殊御主或卡牌可能改变使用时机、可选地点或其他条件。

令咒不是免费的额外攻击牌。用它获得魔力后，仍要正常支付随后打出的牌的费用。

## 一回合怎样进行

回合开始 → 准备阶段 → 部署阶段 → 行动阶段 → 战斗阶段 → 回合结束。

规则原文中的「前哨阶段」对应界面中的「部署阶段」。每个阶段都按本回合顺位依次行动，所有玩家完成后才进入下一阶段。

## 回合开始：先更新局面

1. 按顺位补充手牌，通常补到 3 张。已有 3 张或更多时不抽牌。
2. 展示本回合局势牌，所有玩家恢复牌上标注的魔力，并处理它的效果。
3. 为深山町放置一张明置事件牌，为新都放置一张暗置事件牌。局势或能力另有规定时，再按相应效果处理。
4. 玩家按顺位使用准备阶段能力。

明置事件可以立即查看；新都的暗置事件在行动阶段开始时展示。局势会影响这一回合，事件会影响所在战场的规则或奖励。

## 部署、行动、战斗各做什么

部署：决定这一回合从哪里开始，争取工坊魔力或战场地利。

不在地图上的玩家必须完成合法部署，不能直接结束部署阶段。已经被效果放到地图上的玩家，按相应效果与规则处理。

行动：先处理常规移动，再进行常规出牌。移动决定你参加哪处战斗，出牌决定你投入多少魔力与威力。

战斗：按顺位处理战斗阶段能力，随后计算威力、确定胜者并发放战果。

## 下一回合的顺位

开局先确定首位玩家。每回合结束后，首位顺时针后移一位，随后继续按顺位行动。若开局约定逆时针轮换，则按约定方向进行；每回合重新随机顺位不属于通常规则。

在单人模式中，每次新开一局都会随机确定初始顺位；同一局的后续回合按轮换规则进行。
