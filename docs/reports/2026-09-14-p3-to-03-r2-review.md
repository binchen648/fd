## Prior Blockers Closed

### Producer identity

`EventProducerRef` is now a discriminated non-empty union:

- `card_ability` -> card instance + ability ID;
- `card` -> card instance ID;
- `system` -> stable system identity.

Negative case 38 rejects empty/incomplete producer identity.

### Failed settlement versus terminal state

`failed` is no longer an authoritative trigger terminal state. Effect-settlement failure rolls back and remains non-terminal/unprocessed. `invalidated` may commit only as a successful scheduler revalidation outcome and cannot retain failed effect mutation.

### Cancellation ownership

- forced triggers are not client-cancellable;
- optional cancellation delegates to accepted TO-05 `cancelPolicy` and defaults to forbidden;
- decline and cancellation are distinct;
- permitted explicit cancellation terminates as `cancelled`, executes no trigger continuation, and cannot roll back earlier committed commands;
- cancellation closes scheduler/interaction bookkeeping only; external owners retain source/lifecycle/card-zone/hidden/battle cleanup;
- cancelled trigger identity is replay-protected.
