## Current Boundary

- Phase 3A graph detection is structural (`bind`, `resultVar`, binding expressions, or Phase 3A-only nodes) plus semantic-form routes for selected mechanic batches. `command-spell.gain-mana` routes through `RESOURCE_NUMERIC_CORE_DIRECT_ACTION`; `conversion-magic.preparation` routes through `CARD_ZONE_CORE_DIRECT_ACTION`; Kiritsugu `time-alter.action` routes through scoped `CARD_ACTION_SEMANTICS_MINIMAL_PLAY`; Kayneth `volumen.extra-play` routes through scoped `CARD_ACTION_SEMANTICS_MINIMAL_PLAY_SOURCE_CARD_WITH_COST_RESPONSE`; Olga `astronomical-science.first-loss` routes through scoped `CARD_ACTION_SEMANTICS_MINIMAL_ACTIVATE`; Maiya `military.attach-support-shot` routes through `CARD_ACTION_SEMANTICS_MINIMAL_ADD_TO_ATTACK`; Artoria Alter `sc-artoria-alt-2.angra-mainyu-embrace` routes through scoped `CARD_ACTION_SEMANTICS_MINIMAL_CLOSE`. The Phase 3 ability-id pilot allowlist is currently empty.
- Once classified as Phase 3A, validation or execution failure returns `resolution_failed`; it does not retry through `resolveEffect`.
- `play_selected_cards` has no standalone data-flow fallback executor. It must be called from the server interpreter hook so the shared `playBatch` legality, cost, destination, face-down, trigger, and counter behavior stays authoritative.
- Current checkout contains command spell `command-spell.gain-mana` browser/WS/reconnect/stale Gate C candidate evidence under `RESOURCE_NUMERIC_CORE_DIRECT_ACTION`. Card/Zone direct-action Gate C candidate evidence exists in `e2e/fd-conversion-magic-core-primitive.spec.ts` and remains pending independent reviewer promotion. ADD_TO_ATTACK candidate evidence exists in `e2e/fd-add-to-attack-card-action.spec.ts` for Maiya's exact `attach_card_to_player_attack` shape only. Time Alter's missing `e2e/fd-time-alter-core-primitive.spec.ts` belongs to `CARD_ACTION_SEMANTICS_MINIMAL_PLAY`, not Card/Zone.
- Target discovery and general activation-cost payment remain owned by the transitional legacy/shared interpreter. Golden Eater's optional 7-mana effect is owned by the typed `pay_mana` primitive.
- No status in this document is an independent Gate promotion.
