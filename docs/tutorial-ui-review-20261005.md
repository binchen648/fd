# 教程界面优化 · 2026-10-05

## 本轮范围

新手教程、详细教程、教程目录。沿用深灰、米白、暖金的界面配色和原有切页动画。

- 目录使用两张带场景插图的入口，标明学习章节与查阅专题。
- 新手教程补充六组规则图示：资源、事件放置、部署、移动费用、地区结算、高潮淘汰。
- 新手教程的上一步、下一步移出滚动区，固定在阅读面板底部。
- 详细教程增加本章速查，可直接跳至规则标题；表格使用明确的列标题。
- 调整阅读宽度、文字层级、表格和原文展开区域，适配桌面及横屏小尺寸。
- 保留章节切换焦点、阅读位置、原文展开状态与减少动画设置。

- `node tools/verify-tutorial-module.cjs`：76 项通过，覆盖六章新手、七章详细、阅读状态和原文展开。
- `node tools/verify-guide-layout.cjs`：通过目录与固定底栏、事件和移动图示、速查跳转，以及 1280×720、1920×1080、844×390、740×360 布局检查。
