# 使用体验优化与审核 · 2026-10-06

## 本轮完成

- 保留深色底、白色正文、暖金交互。所有地区的部署位与头像统一为圆形，清除遗留的空方框和加号样式。
- 地图按地区核对玩家变化；未变化地区的头像保留。事件牌、局势牌、公共弃牌分别核对变化，其他玩家移动和牌堆数量变化不会重建局势牌。
- 轮次头像仅在顺序或角色变化时创建；资源变化继续更新现有数字，保留增减反馈。
- 行动按钮保留节点，其他玩家移动与出牌之间切换时不会重新创建整行按钮。地图可操作状态相同时也不反复移除再添加样式。
- 选择弹窗保留已选项；同一选择请求重复到达时不会清空选择或重新播放入场动画。结算内容相同时不重复创建、重播。
- 阶段未变化时不重复设置阶段时钟，避免重新清空交互计时状态。
- 操作区显示当前行动者；出牌、暗置、移动与技能按钮补充不可用原因。被截断的御主、从者名称可以查看完整提示。
- 大量手牌按实际可用宽度计算扇形间距，并在横屏宽度改变时重新排布；退出对局时停止尺寸观察。
- 更新资源版本标记，避免继续使用之前缓存的样式。
