# 经典模式

确认日期：2026-10-04。

## 已确认规则

- 一局 7 名玩家。
- 每名玩家自由选择自己想使用的御主。
- 七个常规职介各随机选择一名从者：Saber、Lancer、Archer、Rider、Caster、Assassin、Berserker。
- 从所有非常规职介中再随机选择一名从者：Ruler、Avenger、Shielder、Foreigner、Moon Cancer。这五类合计选一名，不是各选一名。
- 以这八名从者组成牌池，每名玩家从牌池中随机抽取一名从者。
- 依据用户提供的英文原作者推荐规则，替换此前的随机御主、随机七种职介方案。未加入 Alter Ego 或 Pretender。

## 本次完成范围

按用户决定，先完成模式界面，等角色补齐再开放。

- 单人和多人模式页面都有经典模式卡片，使用 `assets/ui/modes/classic.png`。
- 点击后进入独立规则说明页，返回时回到对应的模式页面。
- 沿用现有模式卡片、背景、边框、按钮及切页动画。
- 开始按钮禁用，提示需补齐七个常规职介及非常规职介的候选从者。
- 现有自选和 3X 入口保留。

- 档案与位阶经验单独识别经典模式，保留现有自选、3X 与乱斗的数据。
- 完成后按既有名次奖励获得 60/42/30/20 经验（第 1～4 名），第 5～7 名为 0；同一场对局防止重复发放。
- 总段位经验共享，经典战绩和经验来源独立显示，档案迁移保留经典模式数据。

尚未实现经典模式随机分配及实际开局；未扩大角色池或启用技能。多人入口只是界面，联网对局仍暂缓。
后续接入前仍需确定抽取池的可用角色，以及御主是否允许重复。
