## 本次界面修复

- 切换章节只更新阅读区，不重建背景、标题和章节导航。
- 每个章节记住当前会话的阅读位置和原文展开状态；返回目录后重新进入仍保留。
- 上一步／下一步重建正文后，将键盘焦点放回对应章节；侧栏操作保留焦点。
- 章节正文沿用原有淡入与位移动画；页面进出场保持原有效果。
- 更新教程资源版本，文案生成文件与七份编辑源同步。

这些阅读位置不构成对局存档功能；刷新网页后不承诺恢复阅读位置。
