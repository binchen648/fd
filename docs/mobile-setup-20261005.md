# 模式准备界面的手机适配

自选、经典说明、3X 的禁用、选御主、圣晶石购买、选从者、准备完成共用响应式组件。

- 按用户要求，仅设计手机横屏。撤销竖屏三列网格与角色资料弹层。
- 手机横屏：候选与资料并排；姓名搜索与职阶筛选；禁用玩家名单横向滑动；购买区和准备完成区可滚动。
- 模式入口：三种模式并排图文卡片；经典模式仍遵循已有开放条件。
- 购买流程：两列商品、44 像素购买按钮、固定可见的完成购点操作。

验证使用桌面浏览器的 844×390、740×360、932×430 横屏视口模拟，覆盖两种可玩模式的完整准备流程以及经典说明界面。这是模式准备 UI 的适配，不代表战斗界面和整个应用已完成手机适配；仍需要手机真机验证触摸、系统键盘和浏览器安全区域。
