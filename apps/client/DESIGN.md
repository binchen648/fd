# FD 对局桌面设计约定

## 视觉方向

界面是“数字化仪式牌桌”，以蓝黑色战场、克制金色描边和真实卡图为主体。原仓库提供实体感与素材基准；本客户端重新组织信息层级，不照搬旧页面的密集面板。

## 桌面结构

1. 顶部阶段条：只呈现回合、阶段、行动者和演示视角。
2. 横向七席：持续显示七名玩家的公开身份、资源和优先状态；单击打开公开情报。
3. 中央战场：四个地点使用实际地点图；玩家头像直接落在所在地点。
4. 公共牌区：局势、事件、地点效果与已公开技能都可悬停预览、单击检视。
5. 右侧决策区：只说明当前决策和服务端返回的可操作数量。
6. 底部操作台：同时展示本人御主、从者、牌库构成、御主技能、三张从者技能和三张手牌。

## 卡牌交互

- 悬停／键盘聚焦：固定位置快速预览真实卡图与中文规则摘要。
- 单击：在屏幕中央打开完整卡图和结构化说明；单击空白处或按 Esc 关闭。
- 非本人牌、公共牌：只可检视。
- 本人牌：只有服务端 `availableActions` 明确关联到该实例时才显示操作按钮。
- 玩家公开情报：绝不展示手牌、未公开技能或暗置牌。

## 约束

- 首版以 1440×900 及以上桌面完整对局为目标；移动端后续单独设计完整布局。
- 背景细网格只用于中央数字牌桌的空间语义，不作为通用装饰。
- 不以音效承担必要反馈；初版所有状态必须仅靠视觉和文本即可理解。
